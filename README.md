# Marked

A personal trade journal and analytics PWA for Forex and Crypto/Web3.

## Stack

- **Vite + React 18 + TypeScript** (strict mode, path aliases via `@/`)
- **TailwindCSS**, class-based dark mode
- **Supabase** (Postgres + Auth)
- **vite-plugin-pwa** — manifest + service worker, installable app shell

## Getting started

```bash
npm install
cp .env.example .env.local 
npm run dev
```
